title: "Tile Map"
description: "Projects a geo-referenced multi-resolution image tile map into the scene.  Map tiles can be obtained from [Bing Maps](https://www.bing.com/mapspreview) or any [WMTS Tile Service](http://www.opengeospatial.org/standards/wmts).  Pre-defined services that access [Stamen Design](http://maps.stamen.com/) (terrain, watercolor, and toner) are provided.  Custom or local WMTS map servers can also be specified.  Map data is cached to disk which enables some limited use completely offline.  The credit line that the selected source's terms of use require (for example \"© OpenStreetMap contributors, © CARTO\" for Carto) is drawn in the bottom-right corner of the map; for Bing it lists the imagery providers covering the area on screen, next to the Bing logo."
image: "satellite.png"
details: "**2.5D rendering.** Checking *2.5D rendering* adds depth to the map while keeping it top-down, so every other display still lines up with it.  Steep ground is shaded darker, using elevation from the free [AWS Terrain Tiles](https://registry.opendata.aws/terrain-tiles/).  Buildings and trees stand up out of the map, their tops drawn further up the screen the taller they are.  There is no light source and nothing casts a shadow, so the map reads the same however it is rotated.  Buildings and trees appear when zoomed in to 3 m and 1.5 m per pixel respectively.  Building outlines and heights come from [OpenStreetMap](https://www.openstreetmap.org/) through the [Overpass API](https://wiki.openstreetmap.org/wiki/Overpass_API), or from Stadia Maps vector tiles; each area is downloaded once and kept on disk for 30 days.  Trees are found in the imagery itself, or come from the woods and trees mapped in OpenStreetMap.  Roofs and treetops can show the imagery that was beneath them.\n\n![Tile Map with 2.5D rendering, showing satellite imagery with trees and buildings standing up from the map](/mapviz/assets/images/mapviz.png)\n\nThe on-map credit for the elevation data is a short form.  The data sets behind the Terrain Tiles each have their own wording, listed in the [Terrain Tiles attribution](https://github.com/tilezen/joerd/blob/master/docs/attribution.md); in the United States, for example, \"3DEP (formerly NED) and global GMTED2010 and SRTM terrain data courtesy of the U.S. Geological Survey.\"\n\n**Topographic map.** Checking *Topographic map* draws contour lines over the imagery, from the same AWS Terrain Tiles elevation data.  Every fifth line is an index contour, drawn heavier and labeled with its height in meters; the labels stay upright however the map is rotated.  The lines are traced from the elevation tiles in view and drawn as lines rather than images, so they stay thin at any zoom.  It works with or without 2.5D rendering; with both on, the lines lie on the shaded ground, under buildings and trees.\n\n**Elevation without a network connection.** The terrain shading and the contour lines can read elevation from disk instead of downloading it.  An elevation set is a `.geo` file and a folder of tiles laid out like the imagery the Multires Image plugin shows (`layer0/tile00000x00000.png` and so on), with heights stored in the Terrarium encoding.  The `make_elevation_set` script builds one, from the AWS Terrain Tiles for an area or from your own elevation models (GeoTIFF, or anything else GDAL reads; heights in feet are converted to meters).  It needs GDAL's Python bindings (`python3-gdal`):\n\n```\n# Download the Terrain Tiles for an area (south west north east):\nros2 run tile_map make_elevation_set terrarium --bounds 29.40 -98.70 29.50 -98.55 --output ~/.map_tiles --name swri_elevation\n\n# Convert your own elevation models, here a USGS 3DEP 1 m tile:\nros2 run tile_map make_elevation_set dem USGS_1M_14_x53y326.tif --output ~/.map_tiles --name swri_1m --attribution \"USGS 3DEP\"\n```\n\nSets are in longitude and latitude unless you add `--projection utm`; `--resolution` sets the pixel size in meters, and `--bounds` crops a DEM.  The Terrain Tiles go down to about 5 m pixels (zoom 15), so a local 1 m model gives much finer contours.  Then set *Elevation* to *Files, else online* or *Files only*.  Where several sets cover the middle of the view, the one with the smallest pixels is used.  The `mapviz_tile_loader` node skips elevation sets, so they can share a folder with imagery tile sets.\n\n**Credits.** The Terrain Tiles are compiled from many data sets, each with its own license and credit wording (see the [Terrain Tiles attribution](https://github.com/tilezen/joerd/blob/master/docs/attribution.md)). tile_map credits Mapzen and the global sources everywhere, and from zoom level 7 on adds the credit of each regional data set (the United States, Canada, Mexico, Europe, Austria, Norway, the United Kingdom, Australia, New Zealand and the Arctic) whose area the view overlaps; the areas are approximate boxes from the [data sources page](https://github.com/tilezen/joerd/blob/master/docs/data-sources.md).  `make_elevation_set` gives a Terrain Tiles set the same credit for its `--bounds`; `--attribution` replaces it.  `make_elevation_set` also writes an `ATTRIBUTION.md` into each set's folder, listing every source's credit and what was done to the data (reprojecting, resampling, converting units).  Keep it with the set if you copy the set to other machines or give it to others."
parameters:
  - name: "Source"
    description: "The name of source of the tile data."
  - name: "Base URL"
    description: "A template URL used to obtain map tiles.  When obtaining map tiles, parameters labeled `{level}`, `{x}`, and `{y}` in the URL will be replaced with appropriate values.  For example, `http://tile.stamen.com/terrain/{level}/{x}/{y}.png` is appropriate for retrieving terrain tiles from Stamen Design."
  - name: "API Key"
    description: "When the `Carto`, `Bing Maps (terrain)` or a `Stamen` source is selected, this field holds that service's API key instead of a URL; enter the key and click the `Save` button in order for tiles to be available.  Without a key, Carto serves an \"API KEY REQUIRED\" image for every tile.  To get a Carto key, sign up or log in at [carto.com/basemaps/apikey](https://carto.com/basemaps/apikey) and create a key in the dashboard (non-commercial use is free up to 5M requests per month, commercial use up to 1M).  You can get a Bing Maps Key from the [Microsoft Developer Network](https://msdn.microsoft.com/en-us/library/ff428642.aspx), and a Stadia Maps key (used by the Stamen sources) from [Stadia Maps](https://client.stadiamaps.com/).  Keys are saved in the Mapviz config as `carto_api_key`, `bing_api_key` and `stadia_api_key`."
  - name: "Max Zoom"
    description: "The maximum zoom level that will be used when requesting tiles."
  - name: "2.5D rendering"
    description: "Draws the depth cues described above.  Off by default; the settings below appear when it is on.  All of them are saved in the Mapviz config under `render_25d`."
  - name: "Terrain"
    description: "Darkens slopes in proportion to how steep they are, whichever way they face.  Flat ground is left as it is.  Saved as `terrain_shading`."
  - name: "Shading"
    description: "How dark the steepest slopes get, from 0 to 100 %.  Saved as `shading_strength` (0 to 1)."
  - name: "Exaggeration"
    description: "Multiplies terrain heights before shading, so gentle slopes still show.  Saved as `exaggeration`."
  - name: "Buildings"
    description: "Draws buildings standing up out of the map, at 3 m per pixel or closer.  Heights come from the `height` tag, else 3.5 m per `building:levels` plus 1 m, else a typical height for the kind of building.  Saved as `buildings`."
  - name: "Building data"
    description: "*OpenStreetMap (Overpass)* needs no key, but a new area can take up to a minute to load on a busy day.  *Stadia vector tiles* uses the Stadia API key entered on a Stamen source.  Saved as `building_source` (`overpass` or `stadia`).  A different Overpass server can be set in the config as `overpass_url`."
  - name: "Trees"
    description: "Draws trees standing up out of the map, at 1.5 m per pixel or closer.  Saved as `trees`."
  - name: "Tree data"
    description: "*From the imagery* finds tree canopy in satellite or aerial photos and fills it with round crowns; map-style sources have no canopy to find.  *OpenStreetMap* uses mapped woods, forests and single trees, from the same download as the buildings.  Saved as `tree_source` (`imagery` or `osm`)."
  - name: "Textures"
    description: "Drapes the imagery over roofs and treetops, lifted with them, instead of drawing them in plain colors.  Where the imagery for a roof hasn't loaded, it is drawn plain.  Saved as `imagery_textures`."
  - name: "Lean"
    description: "How far the top of a building or tree moves up the screen, as a percentage of its height.  Saved as `lean` (1.0 is 100 %)."
  - name: "Topographic map"
    description: "Draws the contour lines described above.  Off by default; the settings below appear when it is on.  All of them are saved in the Mapviz config under `topographic`."
  - name: "Interval"
    description: "Height between contour lines, in meters.  *Auto* picks 1, 2 or 5 times a power of ten from the zoom, so lines get closer together as you zoom in.  Saved as `contour_interval` (0 is Auto)."
  - name: "Labels"
    description: "Labels every fifth line with its height in meters.  Saved as `contour_labels`."
  - name: "Line color"
    description: "The color of the contour lines; labels use a darker shade of it.  Saved as `contour_color`, for example `#a0522d`."
  - name: "Elevation"
    description: "Where the terrain shading and contour lines get heights, shown while either is on.  *Online* downloads the AWS Terrain Tiles.  *Files, else online* uses an elevation set on disk where one covers the middle of the view, and the Terrain Tiles elsewhere.  *Files only* never goes online.  Saved as `elevation_source` (`online`, `local_then_online` or `local`)."
  - name: "Elevation files"
    description: "The folder searched, with the folders in it, for elevation sets (`.geo` files).  Press Enter to look through it again after adding sets.  Saved as `elevation_directory`; the default is `~/.map_tiles`."
